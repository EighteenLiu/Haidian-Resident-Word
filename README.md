# 海淀区农村人居环境报告生成工具

本程序用于根据用户上传的现场检查主数据、村庄与指标字典、道路台账，生成海淀区农村人居环境检查统计表 xlsx 和分析报告 docx。

## 输入文件

源文件支持多选 Excel，程序按工作表和表头语义自动识别，不依赖固定文件名：

- 主数据：包含 `月份`、`编号`、`案件状态`、`检查点位（1级）`、`检查指标（3级）`、`街镇分中心`、`上报扣分案件`、`解决案件库` 等字段。
- 村指标字典：包含 `人居村` 和 `人居指标` 工作表。
- 道路台账：包含 `所属街道`、`小区（村）名称`、`道路`、`备注-别名` 字段。

程序会忽略 Excel 临时锁文件 `~$*.xlsx`。未知文件不会被静默忽略，运行前会阻止生成并提示用户处理。

## 模板文件

Word 模板默认从 `input` 目录自动选择：

- `input/海淀区2026年6月份农村人居环境检查分析报告模板.docx`

xlsx 模板默认优先从 `input` 目录选择：

- `input/附件3：海淀区农村人居环境检查情况统计表模板.xlsx`

如果 `input` 中没有 xlsx 模板，程序会读取 `data/2.人居报告/提交格式` 中的提交样例作为样式来源并另存为输出文件，不会修改原始提交样例。

## 命令行启动

源码版推荐在 PowerShell 中从项目根目录启动：

```powershell
cd E:\Haidian\Haidian-Resident-Word
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

如果当前终端已经激活了项目虚拟环境，也可以运行：

```powershell
cd E:\Haidian\Haidian-Resident-Word
python app.py
```

程序启动后会打开图形界面。源码版运行时会以项目根目录作为程序根目录，默认读取 `config`、`input`，默认输出到 `output`，运行期临时目录固定在项目 `.runtime` 下。

## 操作步骤

1. 按“命令行启动”中的命令启动图形界面。
2. 点击 `选择源文件`，一次选择主数据、村指标字典、道路台账。
3. 点击 `识别`，程序会识别源文件类型并解析报告年份、月份、日期范围；识别时按钮会显示 `正在识别`。
4. 检查文件识别状态。
5. 确认或手动选择 Word 模板、xlsx 模板。
6. 检查解析出的报告年份、月份、日期范围；需要时手动修改。
7. 选择输出目录，点击 `生成报告`。
8. 生成完成后查看输出目录和运行日志。

## 当前业务口径

- 只统计问题数量，不计算分数。
- 不处理村庄常驻人口系数、市级垃圾分类示范小区、严重问题扣分、普通问题扣分、最终得分、合格情况。
- 每月检查轮次默认固定为 2 次，Word 中每轮平均问题数按 `round(问题总数 / 2)` 展示。
- 有效案件默认筛选：报告月份一致、`检查点位（1级）=北部地区`、`上报扣分案件=是`、`案件状态=结案`、`解决案件库=是`，并且镇村、指标能匹配到人居字典。
- 道路台账用于道路识别和校验：未命中道路不静默消失，会进入道路匹配校验清单。
- 当前统计纳入口径按 6 月参考提交表对齐：道路命中台账的案件纳入；道路为空且不是 `考评上报` 的案件纳入；道路未命中台账的案件进入校验清单，不纳入统计。
- 参考提交表额外排除了编号 `2026062300627`。该条为苏家坨镇草厂村 `草场南路（草厂河槽路）` 的 `清扫保洁不到位` 案件，程序已放入 `config/default_rules.yaml` 的 `excluded_case_ids`，后续业务确认后可删除该配置项。
- `sheet1` 的 J:AB 列写入各指标问题数量；A:I 的评分相关列不参与读取、计算或业务判断。
- Word 表 1 最后一行前两个 `总计` 单元格在渲染后自动横向合并，并上下左右居中。
- Word 表 4 先按普通表格渲染，再通过通用后处理合并连续相同镇名单元格。
- Word 表 2 按问题大类分组、组内按数量降序展示，最后一行输出总计；渲染后自动合并第二列连续相同的问题大类，并将最后一行前三个 `总计` 横向合并，上下左右居中。
- Word 表 3 不输出总计行；表 3 标题按标准文件口径在渲染后修正为 `农村人居环境检查发现各村问题数量统计表`。
- Word 表 4 最后一行输出总计，前两个 `总计` 单元格横向合并并上下左右居中。

## 输出文件

默认输出目录为 `output/YYYYMMDD_HHMMSS`，包含：

- `附件3：海淀区农村人居环境检查情况统计表-城环建平台（{month}月）.xlsx`
- `海淀区{year}年{month}月份农村人居环境检查分析报告.docx`
- `道路匹配校验清单.xlsx`
- `运行日志.txt`

统计表中还会生成或更新：

- `sheet1`：24 个村的 J:AB 指标问题数量。
- `数据明细`：有效案件明细，按提交样例保留 37 个字段。
- `未映射指标`：主数据中没有匹配到人居指标字典的小类。

## 常见错误

- 文件无法识别：检查上传文件是否为正确的主数据、村指标字典、道路台账，且不是 `~$` 临时锁文件。
- 缺少模板：手动选择 Word 模板或 xlsx 模板。
- 有效数据为 0：检查报告月份、筛选配置和源数据字段。
- 道路未命中：查看 `道路匹配校验清单.xlsx`，当前默认只警告并保留统计。
- 指标未映射：查看统计表中的 `未映射指标` 工作表，并补充字典映射。

## 打包运行

打包后的 exe 以 exe 所在目录作为程序根目录，默认从同级 `config` 读取规则文件、从同级 `input` 读取模板文件，并默认输出到同级 `output`。因此交付目录需要保留：

- `海淀农村人居环境报告生成工具.exe`
- `config/`
- `input/`
- `README.md`
- `人居报告生成逻辑对应关系.md`

临时目录仍固定在 exe 同级 `.runtime` 下，不写入 C 盘。未明确要求时不生成压缩包。
